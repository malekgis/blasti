# بلاصتي · Blasti

**بلاصتك في طابور الوقود.** موقع عام لتنظيم التزوّد بالوقود ومحاربة التهريب في ولاية تمنراست.

## كيف يعمل

1. **التسجيل:** السائق يفتح الموقع (أو يمسح ملصق QR في المحطة)، ويصوّر لوحة مركبته. ثم يختار نوعها (سيارة، دراجة نارية، 4×4، بيكاب، شاحنة، حافلة، جرار) وقسمه (نساء أو رجال، والدولة للوحات المسجّلة فقط) ونوع الوقود.
2. **التذكرة:** يأخذ رقمه ورمز QR خاصاً بتذكرته، والساعة التي يدخل فيها. تُحفظ صورة المركبة ورقم لوحتها.
3. **من لا يملك هاتفاً:** يسجّله مقهى الإنترنت أو شباك البلدية، ويطبع له التذكرة.
4. **حاجز الدخول:** لا يُفتح إلا بتذكرة صالحة، في المحطة الصحيحة، وفي وقتها.
5. **حاجز الخروج:** يُفتح بنفس التذكرة، مرة واحدة، ولمن دخل من حاجز الدخول فقط. المركبة التي أُدخلت من جهة الخروج تُكشف فوراً.
6. **تصاريح دائمة برمز QR:** لصهريج نفطال، وشاحنة قارورات الغاز، والحماية المدنية (تصدرها الولاية)، وللصيانة (يصدرها مدير المحطة ليوم واحد).
7. **الرقابة:**
   - كل فتح يدوي يُسجَّل.
   - كل مركبة تبقى داخل المحطة أكثر من 30 دقيقة تظهر للمدير.
   - إذا خرج من المضخات وقود أكثر مما يحق للمركبات التي دخلت، تظهر المحطة بالأحمر عند الولاية.

## الخطوة 1: نشر الموقع على GitHub (مجاناً)

1. أنشئ حساباً على **github.com**.
2. اضغط **New repository**:
   - الاسم: `blasti`.
   - النوع: **Public**.
   - ثم **Create repository**.
3. اضغط **uploading an existing file**، واسحب **كل** الملفات والمجلدات (`index.html` و`css` و`js` و`supabase` و`README.md` و`.nojekyll`)، ثم **Commit changes**.
4. افتح **Settings ← Pages**:
   - في **Source** اختر **Deploy from a branch**.
   - في الفرع اختر **main** والمجلد **/ (root)**.
   - اضغط **Save**.
5. بعد دقيقة أو دقيقتين يصبح موقعك على العنوان: `https://اسم-حسابك.github.io/blasti/`

في هذه المرحلة يعمل الموقع **بوضع العرض**: كل شيء يعمل، لكن البيانات محفوظة في كل هاتف وحده. هذا مناسب لعرض الفكرة على الوالي.

## الخطوة 2: قاعدة البيانات الحقيقية (Supabase)

هذه الخطوة تجعل الهواتف والحواجز والمحطات كلها تتشارك نفس البيانات.

1. أنشئ حساباً على **supabase.com**، ثم **New project**. اختر أقرب منطقة (Europe).
2. افتح **SQL Editor**، والصق محتوى الملف `supabase/schema.sql` كاملاً، ثم اضغط **Run**.
3. افتح **Table Editor ← stations**، وعدّل أسماء المحطات لتطابق محطات الولاية الحقيقية. يمكنك أيضاً حذف محطات أو إضافة غيرها.
4. افتح **Project Settings ← API**، وانسخ **Project URL** و**anon public key**.
5. في GitHub عدّل الملف `js/config.js`:
   ```js
   MODE: "supabase",
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJ...",
   ```
   ثم **Commit changes**.
6. **أغلق التسجيل المفتوح للحسابات:** في **Authentication ← Sign In / Providers ← Email** عطّل **Allow new users to sign up**. هكذا لا ينشئ الحسابات إلا الولاية.

## الخطوة 3: حسابات العمال

لكل جهاز عند حاجز، ولكل مدير محطة، ولمصالح الولاية:

1. **Authentication ← Users ← Add user** (بريد وكلمة سر، وفعّل **Auto Confirm**).
2. في **SQL Editor**، أضف الدور لكل حساب. أمثلة:
   ```sql
   insert into public.staff (user_id, role, station_id, name)
   select id, 'wilaya', null, 'مصالح الولاية' from auth.users where email = 'wilaya@exemple.dz';

   insert into public.staff (user_id, role, station_id, name)
   select id, 'manager', 's1', 'مدير محطة وسط المدينة' from auth.users where email = 'manager.s1@exemple.dz';

   insert into public.staff (user_id, role, station_id, name)
   select id, 'gate', 's1', 'حاجز محطة وسط المدينة' from auth.users where email = 'gate.s1@exemple.dz';
   ```

| الدور | ماذا يستطيع |
|---|---|
| `gate` | مسح التذاكر عند حاجزي محطته فقط. لا يستطيع الفتح اليدوي. |
| `manager` | كل ما سبق، والطابور، والوقود والمضخات، والعدّاد، والفتح اليدوي، وتصاريح الصيانة. |
| `wilaya` | كل المحطات، والقواعد، ومركبات الدولة، وتصاريح نفطال والغاز والحماية المدنية. |

## الخطوة 4: في المحطة

- **عند كل حاجز:** هاتف أو لوحة إلكترونية مسجّلة بحساب `gate`. افتح «الحاجزان»، واختر حاجز الدخول أو الخروج، ثم اضغط **تشغيل الماسح**. الكاميرا تقرأ الرموز باستمرار.
- **الملصقات:** من «ملصقات QR» اضغط **طباعة الملصقات**. كل ملصق يفتح الموقع باسم محطته.
- **ممر الخروج:** يُنصح بتركيب مسامير أحادية الاتجاه، حتى لا تدخل أي مركبة من جهة الخروج.
- **ربط محرّك الحاجز بالنظام (مرحلة لاحقة، غير موجودة في هذا الكود):** جهاز صغير (مثل ESP32 مع مُرحِّل) يفتح الحاجز آلياً عند الضوء الأخضر. إلى ذلك الحين، يضغط الحارس زر الحاجز فقط عندما تكون الشاشة خضراء، وكل شيء مسجّل.

## تغيير الاسم

في `js/config.js` عدّل `APP_NAME` و`TAGLINE`.

## ملاحظات مهمة قبل الإطلاق الرسمي

- **حماية المعطيات الشخصية:** أرقام اللوحات والصور معطيات شخصية (القانون 18-07). للإطلاق الرسمي، يجب أن تستضيف الولاية قاعدة البيانات على خادم في الجزائر بعد موافقة السلطة الوطنية لحماية المعطيات. الكود مكتوب بـ PostgreSQL عادي، فيمكن نقله إلى أي خادم.
- **التسجيلات الوهمية:** كل لوحة لها تذكرة واحدة فقط، والحارس يقارن صورة المركبة عند الحاجز. يمكن لاحقاً إضافة تأكيد برسالة SMS.
- **قراءة اللوحة آلياً:** اقتراح فقط، والسائق يتأكد دائماً من الأرقام قبل المتابعة.
- **حدود الخطة المجانية:** مشروع Supabase المجاني يتوقف إذا لم يُستعمل عدة أيام، وله حدود في الحجم. للاستعمال الحقيقي استعمل خطة مدفوعة أو خادم الولاية.
